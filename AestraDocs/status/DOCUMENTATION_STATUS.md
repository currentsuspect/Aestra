## Historical context

The original report catalogued an earlier documentation layout and listed
planned audio, DSP, and plugin work. Aestra now contains substantial work in
those areas, so its coverage and readiness claims must not be used for product
or engineering decisions.

For documentation maintenance, add internal design and engineering notes to
the appropriate `AestraDocs/` folder and public material to `docs/`. Validate
both surfaces with `scripts/docs-check.sh` before considering a documentation
change complete.
