AESTRA v0.8.1-alpha (early access)
==================================

Thank you for trying Aestra this early. This is the version shown in the video.
It is an alpha: the main parts work, some parts are rough, and some features are
still being built. You are one of the first people outside the studio to use it.

STARTING IT
-----------
Windows: unzip the folder anywhere, then open Aestra.exe.
         Windows may warn about an unknown publisher ("Windows protected your PC").
         Click "More info", then "Run anyway". The app is not code-signed yet.
Linux:   extract the folder, then run ./Aestra from inside it.
         It needs SDL2, FreeType, ALSA and libsecret, which most desktops already have.

Keep the AestraAssets folder next to the app. The app loads its fonts from there.

WHAT TO EXPECT
--------------
- This is the first Windows build handed out. Windows has had less testing than
  Linux, so you are more likely to hit problems there.
- Plugin support is still limited. Some plugins may not load.
- Save often. Projects made with this alpha may not open in later versions.
- Crashes can happen. If Aestra crashes, the Versions panel offers a recovery card
  the next time you open the project.

TELLING US WHAT HAPPENED
------------------------
Reply to the email that brought you this download, or write to hello@aestra.studio.
The most useful report says what you were trying to do, what happened instead, and
includes a screenshot if you can. Short notes are fine.
