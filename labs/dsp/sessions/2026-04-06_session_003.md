## Key Findings

### Benchmark Variance (Local Machine)

5 consecutive runs on the same binary:

| Algorithm | Range | CV |
|-----------|-------|-----|
| Cubic | 43–65 Mf/s | ~20% |
| Sinc8 TURBO | 27–44 Mf/s | ~22% |
| Sinc16 TURBO | 10–26 Mf/s | ~35% |
| Sinc64 TURBO | 8–13 Mf/s | ~20% |

The ranking is consistent (Sinc8 > Sinc16 > Sinc64) but absolute numbers
are meaningless. Cannot make performance claims on these numbers.

### CI Benchmark Solution

Created `.github/workflows/dsp-benchmark.yml` that:
- Builds SincBenchmark in Release mode on ubuntu-22.04
- Runs 10 iterations (configurable via workflow_dispatch)
- Reports results as markdown table in job summary
- Uploads raw JSON as artifact
- Triggers on DSP code changes or manual dispatch

First CI run will establish baseline with controlled environment.
