## Rounds

### Round 1 — GLSL-Style Free Functions for Vectors

**Hypothesis**: Add `distance()`, `reflect()`, `project()`, `lerp()`, and `clamp()` overloads for Vector2/3/4 to make the API feel "boring" and consistent with standard math library expectations.

**What changed**:
- `distance(a, b)`: Euclidean distance via `(a - b).length()`
- `reflect(v, n)`: `v - n * 2 * dot(v, n)` for all vector types
- `project(v, onto)`: projection with zero-vector guard
- `lerp(a, b, t)`: vector linear interpolation for all vector types
- `clamp(v, min, max)`: component-wise and scalar variants for all vector types
- Clamp uses explicit ternary to avoid name shadowing between vector and scalar overloads
- Added corresponding tests in MathTests.cpp

**Gotcha**: Vector `clamp` overloads shadowed the scalar `clamp` inside their own bodies. Fixed by using explicit ternary expressions instead of calling `clamp(float, float, float)`.

**Result**: ✅ PASS — tests exit 0, benchmark XRUN rate 0.005%, miss rate 0.066% (both well under 0.1% threshold)
