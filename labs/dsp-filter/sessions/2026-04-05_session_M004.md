# DSP Filter Lab Optimization Session M004

## Purpose

Run a bounded optimization loop on the filter subsystem using the current DSP
lab.

## Baseline

- Hard gate: `./labs/dsp-filter/run_eval.sh` -> `accept`
- Advisory context: `AestraAudioPerformanceTest` showed the DSP density lane,
  but with visible run-to-run noise

## Rounds

### Round 1 — Reject

- Hypothesis: Hoist inner-loop branches and use pointer-walk loops in
  `processBlock()`.
- Result: hard gate passed, advisory DSP density regressed.
- Action: rejected and reverted.

### Round 2 — Reject

- Hypothesis: Inline the common `TwoX` oversampling math directly inside
  `processBlock()`.
- Result: hard gate passed, advisory DSP density still mixed/worse.
- Action: rejected and reverted.

### Round 3 — Accept

- Hypothesis: Skip `updateInternal()` entirely once parameters have already
  converged and there is no pending coefficient update.
- Result: hard gate passed. Advisory performance remained noisy, but this
  change is a defensible dead-work elimination in the settled-state path.
- Action: kept.

## Outcome

- Accepted change: settled-state short-circuit in `updateInternal()`
- Rejected changes: two hot-loop reshapes that did not survive advisory timing
- Remaining limitation: the lab still lacks a trusted filter-specific
  performance lane
