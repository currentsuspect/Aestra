## Hypothesis

Three vulnerabilities identified in S001 can be fixed with targeted one-to-three-line changes:
- RTM-009: Wrap clip color `std::stoul` in try/catch (same pattern as lane color)
- RTM-010: Add bounds validation to plugin cache loader (count cap + string length cap)
- RTM-011: Check `fread` return value in MetronomeEngine WAV parser

After fixes, proof-of-fix tests must pass and PoC-generated attack files must be rejected.

## Phase 1: Fixes

### Fix 1: RTM-009 — Clip color stoul crash
**File:** `Source/Core/ProjectSerializer.cpp:691`
**Change:** Wrapped `std::stoul` in try/catch with `0xFFFFFFFF` fallback (same pattern as line 628)
```cpp
// Before:
if (cj[c]["color"].isString()) {
    clip.colorRGBA = static_cast<uint32_t>(std::stoul(cj[c]["color"].asString()));
}
// After:
if (cj[c]["color"].isString()) {
    try {
        clip.colorRGBA = static_cast<uint32_t>(std::stoul(cj[c]["color"].asString()));
    } catch (const std::exception&) {
        clip.colorRGBA = 0xFFFFFFFF;
    }
}
```

**Audit for parallel call sites:** Scanned all 10 `std::stoul`/`std::stoi`/`std::stod`/`std::stof` calls in `Source/`. Results:
- ProjectSerializer.cpp:628 — already try/catch protected (SEC-001)
- ProjectSerializer.cpp:692 — **FIXED** (this session)
- HeadlessExportMain.cpp:66,68,72 — CLI args, somewhat trusted input (noted for RTM-016)
- FileBrowser.cpp:3947,3953 — already try/catch protected
- TrackUIComponent.cpp:370,474,744,1416 — already try/catch protected, internally-generated input

**No more unprotected `stoul`/`stoi` on external input in Source/.**

### Fix 2: RTM-010 — Plugin cache unbounded allocation
**File:** `AestraAudio/src/Plugin/PluginScanner.cpp:361-373`
**Changes:**
1. Count cap: `kMaxCachedPlugins = 10000` — rejects cache files claiming >10K plugins
2. String length cap: `kMaxStringLen = 65536` — rejects any metadata string >64KB
3. `file.good()` checks after `fread` — returns empty string on read failure
```cpp
// Before:
uint32_t count;
file.read(reinterpret_cast<char*>(&count), sizeof(count));
auto readString = [&file]() -> std::string {
    uint32_t len;
    file.read(reinterpret_cast<char*>(&len), sizeof(len));
    std::string s(len, '\0');
    file.read(s.data(), len);
    return s;
};

// After:
constexpr uint32_t kMaxCachedPlugins = 10000;
if (count > kMaxCachedPlugins) return false;
constexpr uint32_t kMaxStringLen = 65536;
auto readString = [&file]() -> std::string {
    uint32_t len;
    file.read(reinterpret_cast<char*>(&len), sizeof(len));
    if (!file.good()) return "";
    if (len > kMaxStringLen) return "";
    std::string s(len, '\0');
    file.read(s.data(), len);
    if (!file.good()) return "";
    return s;
};
```

### Fix 3: RTM-011 — MetronomeEngine fread unchecked return
**File:** `AestraAudio/src/Playback/MetronomeEngine.cpp:122,132`
**Changes:** Both 16-bit and 24-bit `fread` calls now check return value; return `false` if file is truncated
```cpp
// 16-bit path:
size_t itemsRead = fread(rawData.data(), 2, numSamples * numChannels, file);
if (itemsRead != static_cast<size_t>(numSamples * numChannels)) {
    fclose(file);
    return false;
}

// 24-bit path:
size_t bytesExpected = numSamples * numChannels * 3;
size_t bytesRead = fread(rawData.data(), 1, bytesExpected, file);
if (bytesRead != bytesExpected) {
    fclose(file);
    return false;
}
```
