# AestraVerb Quality Lab

This directory contains quality measurement artifacts for AestraVerb.

## Files

- `reverb_quality_baseline.json` — Machine-readable quality metrics
- `reverb_quality_baseline.md` — Human-readable quality report
- `impulse_room.wav` — Room mode impulse response
- `impulse_hall.wav` — Hall mode impulse response
- `impulse_plate.wav` — Plate mode impulse response
- `noiseburst_room.wav` — Room mode noise burst response
- `noiseburst_hall.wav` — Hall mode noise burst response
- `noiseburst_plate.wav` — Plate mode noise burst response
