### New Tool: AestraReverbQualityLab

A standalone C++ executable that:
1. Generates impulse responses for Room, Hall, Plate modes (65536 samples @ 48kHz)
2. Generates noise burst responses (500-sample white noise)
3. Computes quality metrics:
   - **Tail decay**: T20, T40, T60 via Schroeder backward integration
   - **Decay smoothness**: monotonicity check, max rebound detection
   - **Spectral profile**: Low (20-500Hz), Mid (500-4kHz), High (4k-20kHz) energy ratios
   - **Metallic ringing proxy**: Spectral crest factor, peak frequency
   - **Stereo behavior**: Early/late correlation, mono fold-down peak, width proxy
   - **Transient smear**: Bloom time (running RMS -3dB), early reflection density
   - **Stability**: NaN/Inf detection
4. Outputs JSON and Markdown reports
5. Writes WAV files for listening inspection

### FFT Implementation
Simple iterative Cooley-Tukey FFT (power-of-2 sizes) for spectral analysis.
No external dependencies.

### WAV Writer
Minimal RIFF WAV 32-bit float stereo writer. No external dependencies.

## Quality Weaknesses Identified

### 1. Late Tail Mono Collapse Risk (Room & Plate)

**Severity:** Medium  
**Evidence:** Late correlation 0.974 (Room), 0.967 (Plate)  
**Root cause:** The width matrix in Output/Mix uses:
```cpp
const float widthL = wetL * control.widthMain + wetR * control.widthCross;
const float widthR = wetR * control.widthMain + wetL * control.widthCross;
```
Where `widthMain = 1.0f + width` and `widthCross = 1.0f - width`. For width=0.7:
- widthMain = 1.7
- widthCross = 0.3

This means both channels contain significant crossfeed. Over time, the FDN lines
feed similar energy into both channels, causing correlation to increase.

**Recommendation for Session 011:**
- Add a small decorrelation signal to the late tail
- Or reduce widthCross for late tail processing
- Or apply the width matrix only to early reflections, not the FDN output

### 2. Plate Metallic Peak at 1406 Hz (20.9 dB)

**Severity:** Low-Medium  
**Evidence:** Spectral crest factor 11.1, peak at 1406 Hz  
**Root cause:** The Plate post-allpass stages (101 and 77 sample delays at 48kHz)
have resonant frequencies. The 1406 Hz peak may be a resonant mode of the allpass
chain.

**Recommendation for Session 011:**
- Investigate whether the allpass feedback coefficient (g=0.6) is causing resonant buildup
- Consider slight damping on the post-allpass stages
- Compare with Room/Hall (no post-allpass) which have lower crest factors

### 3. Early Reflection Density Not Detected

**Severity:** Low  
**Evidence:** Early density = 0 for all modes  
**Root cause:** The detection threshold (`directPeak * 0.02`) may be too high, or
early reflections are very close to the direct sound and blended.

**Recommendation:** Lower detection threshold or use a different metric (e.g.,
autocorrelation of the first 50ms).

## Risks Introduced

1. **Quality lab is not a regression test** — it doesn't fail on bad metrics, it
   only reports them. Future sessions must manually compare against this baseline.

2. **FFT is naive O(n log n)** — fine for 2048-point analysis, but not suitable
   for real-time use.

3. **WAV files are large** — 6 × 524KB = ~3MB. These are generated artifacts
   that could be gitignored if desired, but they're useful for CI artifact uploads.

3. Use different output coefficients for left/right in the FDN feedback loop
