## Key Findings

### 1. FDN Delay Read is the dominant hotspot (34.5%)
- **8 delay lines × cubic Hermite = 32 memory reads per sample**
- Memory latency bound, not compute bound
- The cubic Hermite interpolation is expensive but justified by quality
- **Session 004 target #1**: Consider prefetch strategies, cache-friendly ordering, or reduce interpolation order for long delay lines

### 2. Early Reflections is #2 (14.7%)
- 12 taps with scalar accumulation
- **Session 004 target #2**: Partial vectorization with 4-wide partial sums possible

### 3. FDN Feedback/Matrix benefits from SIMD (14.2% → 10.9%)
- SSE4.1 path saves ~3.3 percentage points
- On AVX2 this would shrink further (projected ~7-8%)

### 4. Profiling overhead is measurable but acceptable
- Non-profile build: 1.54 Ms/s (Room)
- Profile build: 0.91 Ms/s (Room)
- **Overhead: ~41%** — expected due to 18 `std::chrono` calls per sample
- This is why profiling is compile-time gated and OFF by default

### 5. Quality guardrails all pass
- No NaN/Inf in any mode
- Max peak: 1.00 (healthy)
- Stereo correlation: no mono collapse detected
- Tail decay: positive (reverb tail grows as expected with sustained input)

## Recommended Session 004 Target

**FDN Delay Read (34.5%)** — This is the clear winner for optimization effort.

Potential approaches:
1. **Prefetching**: Already have `__builtin_prefetch` but could be more aggressive
2. **Cache blocking**: Process delay lines in batches to improve L1 cache hit rate
3. **Hybrid interpolation**: Use cubic for short lines (high feedback count), linear for very long lines
4. **SIMD delay reads**: If delay offsets are similar across lines, could batch reads
