### Production Change: Late-Tail Stereo Decorrelation

Added a mode-specific late-tail width coefficient in the Output/Mix stage,
after plate post-allpass and before the width matrix:

```cpp
float kDecorr = 0.0f;
if (mode == Mode::Room) kDecorr = 0.60f;
else if (mode == Mode::Plate) kDecorr = 0.60f;
if (kDecorr > 0.0f) {
    const float diff = (wetL - wetR) * kDecorr;
    wetL += diff;
    wetR -= diff;
}
```

**Properties:**
- Preserves mono fold-down exactly: `(wetL+diff) + (wetR-diff) = wetL + wetR`
- Zero cost for Hall (k=0, branch not taken)
- Only 3 float ops per sample for Room/Plate
- Applied before width matrix, so width control still works normally

### Production Change: Deterministic LFO Seed

Changed `clearBuffers()` from:
```cpp
std::mt19937 rng{std::random_device{}()};
```
to:
```cpp
std::mt19937 rng{0xAE57A000u};
```

This makes the reverb impulse response deterministic across runs, enabling
reliable before/after quality comparison. The random modulation is still
present and musically valid; only the initial phase is fixed.

### Quality Lab Fix: Hall Mode Parameter

The quality lab was passing `1.0f` for Hall mode, but `modeIndex()` computes:
```cpp
std::clamp(static_cast<int>(std::round(getParameter(kMode) * 2.0f)), 0, 2)
```

With `kMode` range 0.0–1.0:
- 0.0f → round(0) = 0 → Room ✅
- 0.5f → round(1) = 1 → Hall ✅
- 1.0f → round(2) = 2 → Plate ❌

The quality lab was testing Hall as Plate. Fixed:
```cpp
modes.push_back(measureMode("hall", 0.5f, 0.9f, 0.9f, 0.85f, ...));
modes.push_back(measureMode("plate", 1.0f, 0.7f, 0.6f, 0.8f, ...));
```

## Root Cause Analysis

### Why Was Hall Correlation Healthy?

True Hall mode (T60=1349ms, not 816ms as previously measured) has longer delay
lines and more modulation depth. The FDN naturally produces more decorrelation
over longer tails. Hall never had a correlation problem — the Session 010
measurement was actually Plate mode with Hall parameters.

### Why Did Room/Plate Have High Correlation?

Room and Plate have shorter tails and less aggressive modulation. The FDN
feedback matrix mixes energy evenly across channels over time. Without explicit
decorrelation, the late tail converges toward correlated energy.

2. **Deterministic LFO seed** — ACCEPTED

3. **Quality lab Hall mode parameter fix** — ACCEPTED
   - Corrects a measurement bug that reported Plate metrics as Hall

## Risks Introduced

1. **T60 shift (-3% Room, -4% Plate)** — The decorrelation changes energy
distribution slightly. This is within acceptable bounds but should be monitored
in listening tests.

2. **k=0.60 may be too aggressive for some material** — If users report
excessive stereo widening or phase issues, k can be reduced to 0.35–0.50.

3. **Deterministic seed removes per-activation variation** — Users who activate
and deactivate the plugin repeatedly will get identical LFO phases. This is
actually desirable for consistency but differs from previous behavior.
