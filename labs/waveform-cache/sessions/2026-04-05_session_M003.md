# Waveform Cache Optimization Session M003

## Purpose

Run a bounded optimization loop on the waveform-cache lab and keep only changes
that survive the deterministic correctness gate.

## Baseline

- Command: `./labs/waveform-cache/run_eval.sh --rebuild`
- Result: `accept`
- Baseline advisory sample: about `0.0466 ms` average read latency and
  `0.175 ms` max latency, with `92` writer rebuilds

## Rounds

### Round 1 — Accept

- Hypothesis: remove per-build info logging from `buildFromRaw()`
- Result: correctness stayed green; advisory latency improved materially on the
  first follow-up run
- Action: kept

### Round 2 — Reject

- Hypothesis: replace repeated `getPeak()` calls with direct pointer access in
  `getPeakRange()` and `buildNextLevel()`
- Result: correctness stayed green, but the advisory latency signal was not
  better than round 1
- Action: rejected and reverted

## Outcome

- Accepted change: remove per-build info logging from waveform-cache rebuilds
- Remaining limitation: advisory timing remains noisy, so this is still not a
  fully trusted numeric benchmark lab
