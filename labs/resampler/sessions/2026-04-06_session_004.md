## Key Observations

1. **GCC 15 register allocation is fragile** — removing `srcNextDiff` (a variable
   that appears to be a dead write in the normal path) caused 64-108% regressions
   across ALL cases. The compiler uses this variable for register allocation hints.
2. **`ivdep` is harmful with explicit unrolling** — the pragma confused GCC 15's
   auto-vectorizer. The unroll-by-8 already provides ILP; ivdep made it worse.
3. **Tap-count dispatch is too expensive** — any branching in the hot loop costs
   more than the generic path, even for very small tap counts (Linear=2).
4. **Local optimum reached** — after 22 accepted rounds across 3 prior sessions,
   the code is at a local optimum for this compiler/hardware combination.
