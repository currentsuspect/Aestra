## Key Observations

1. **Dot product unrolling** (round 01) provided incremental improvement over the ivdep + SSE4.1 approach from session 001. The compiler was already doing decent auto-vectorization, but explicit unrolling gives it known iteration counts.
2. **Dead branch removal** (round 02) — the `if (rel < 0)` check was never true because bitwise AND with a power-of-2 mask always produces non-negative results. This was a leftover from the original `getWindow()` implementation that used `%` (which can return negative for negative operands).
3. **Stereo fast path** (round 03) was the biggest win of this session. All benchmarks use 2 channels, so the `m_channels == 2` check is always true. Unrolling to two independent accumulators lets the CPU schedule both dot products in parallel.
4. **`__restrict__`** (round 04) had marginal impact — the compiler was already inferring non-aliasing from context. Still worth keeping as it documents intent.
5. **Hoisting per-frame constants** (round 05) eliminated redundant double subtractions in the output loop. The gains were significant for cases with many output samples per input frame (upsampling).
