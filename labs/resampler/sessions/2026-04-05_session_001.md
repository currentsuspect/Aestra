## Outcome

- **15 rounds accepted**, **1 round rejected** (round 15 attempt 1: hoisting `writePos`)
- All 22 unit tests pass after every accepted round
- SIMD/scalar equivalence preserved (RMS < 1e-6, max error < 1e-5)
- Offline render regression passes (correlation > 0.995)
- Significant cumulative improvement across all benchmark cases
- Machine has high variance (CV > 5% on many cases) — baselines need refresh on quieter hardware

## Key Observations

1. **Power-of-2 bitwise AND** was the single biggest class of wins (rounds 07, 08). The ring buffer size (128) and polyphase count (256) are both powers of 2, making `%` → `&` a free optimization.
2. **Inlining `getWindow()`** (round 11) eliminated function call overhead and the `size == 0` bounds check per output sample.
3. **Reducing mirror factor** (round 10) from 3 to 2 cut per-frame writes by 33% with no correctness impact — `writePos + rel` max is 254, which fits in 256 slots.
4. **Dead code removal** (round 12) — `m_historyFilled` was written every frame but never read. Removing it eliminated a conditional branch.
5. **Hoisting member variables to locals** (round 14) reduced memory traffic. But hoisting `writePos` (round 15 attempt 1) was wrong because it changes during the loop.
6. **SSE4.1 target attribute** (round 15 retry) enabled auto-vectorization of the scalar dot product without requiring AVX2.
7. **`#pragma GCC ivdep`** (round 16) further improved vectorization of the dot product loop.
