## Key Observations

1. **Mutex was on write side** — `release()` was called from UI thread, so mutex
   contention wasn't an RT issue but caused UI thread blocking during heavy
   sample loading/unloading.
2. **Ring buffer capacity 4096** — generous but not excessive. Should never fill
   under normal use (a single sample load/release cycle produces ~1-2 entries).
3. **No alloc changes** — this is a structural improvement, not a memory reduction.
   The MemoryBenchmark numbers are unchanged (within machine variance).
