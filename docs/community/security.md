# Security Policy
**Aestra Studios** – *Last Updated: 2026-04-04*

Thank you for helping keep **Aestra** safe and secure.

---

## 🧩 Supported Versions
| Version | Supported |
|----------|------------|
| `0.x` public pre-beta line (current) | ✅ Active |
| Older pre-release snapshots / untagged commits | ⚠️ Best-effort only |

The public roadmap target is **v1 Beta in December 2026**. Until then, this repository should be treated as a pre-beta engineering line rather than a supported `1.x` release family.

---

## 🔒 Reporting a Vulnerability
If you discover a security issue or exploit in Aestra:

1. **Do not** publicly disclose the details.
2. Email **security@aestra.studio** with the subject line  
   `SECURITY: [brief issue summary]`.
3. Include:
   - The affected version / commit hash  
   - Reproduction steps or sample project  
   - Expected vs. actual behavior  
   - Any crash logs or stack traces

Reports will be acknowledged within **72 hours**.

---

## 🎯 Our Commitment
- We review all reports seriously and confidentially.  
- We patch verified vulnerabilities as quickly as possible.  
- Responsible disclosure contributors will be credited in the next changelog (unless anonymity is requested).

---

## 🧠 Helpful Notes
- Aestra runs **locally**; it does not connect to the internet except for optional update checks.  
- Please also report potential data-loss bugs, crash loops, or performance regressions — we treat those as high-priority.

---

Thank you for helping make Aestra a trustworthy tool for creators worldwide.
