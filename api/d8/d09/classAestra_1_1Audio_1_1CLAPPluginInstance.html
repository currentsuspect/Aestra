Detailed Description

CLAP plugin instance implementation.

Wraps a CLAP plugin and provides the IPluginInstance interface. CLAP is a simpler API than VST3 with a C-based interface.

Key differences from VST3:

  • C-based API (not COM)
  • Single plugin descriptor per entry
  • Simpler audio processing setup
  • Built-in thread-safety annotations
