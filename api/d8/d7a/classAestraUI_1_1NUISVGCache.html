Detailed Description

Cache for rasterized SVG images to avoid redundant rasterization.

This cache stores RGBA buffers for SVGs that have been rasterized at specific dimensions and tint colors. It uses an LRU-style eviction policy with time-based cleanup to prevent unbounded memory growth.
