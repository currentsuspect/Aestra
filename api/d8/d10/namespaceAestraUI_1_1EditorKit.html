Detailed Description

Shared drawing for built-in plugin editors.

Every built-in editor used to carry its own copy of the same arc routine and, in Sat, OTT, Filter and LFO, the same rotary knob, differing only in an accent colour and a few pixel constants. Those copies drifted one constant at a time. This is the one copy. An editor keeps what is genuinely its own (layout, accent, visualizer) and asks the kit to draw the parts that are the same.

Pure rendering: no parameter access, no input. Input lives in AestraPanelWindow::handleKnobDrag(), next to the cursor capture it drives.
