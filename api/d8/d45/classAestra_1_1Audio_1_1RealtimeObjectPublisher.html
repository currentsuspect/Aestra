Detailed Description

template<typename T>
class Aestra::Audio::RealtimeObjectPublisher< T >

Publishes shared control-thread ownership as a non-owning real-time pointer.

One control thread owns publish(), owner(), and collectRetired(). One real-time reader uses acquireRealtime()/releaseRealtime(). Replaced objects remain owned by the control thread until the real-time hazard no longer references them, so the last shared_ptr release never occurs in the callback.
