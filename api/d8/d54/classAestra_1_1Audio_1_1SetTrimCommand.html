Detailed Description

Command to change a channel's trim offset (dB).

Trim is consumed on the RT side through the ContinuousParamBuffer (like the fader/pan readouts), so execute/undo/redo push both the MixerChannel member (serialized project state) and the buffer slot (live RT value), then request a graph rebuild for parity with the other mixer mutations.
