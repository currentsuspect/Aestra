Detailed Description

Audio buffer data for clip sources.

Samples live in exactly one of three storages. Decoded audio is float32 (4 bytes per sample), which is most of a session's memory: a 4-minute stereo track is ~92 MB. When a buffer's samples are exactly the values of 16- or 24-bit PCM (a 16/24-bit WAV or FLAC), tryCompact() keeps them as that PCM (2 or 3 bytes per sample) and everything reads them back through copyFloats(). The conversion is exact, so what the engine plays is bit-identical; a buffer that is not exactly representable (MP3, a rendered float result, anything processed) stays float32 untouched.

bool Aestra::Audio::AudioBufferData::tryCompact ( )

Keep the samples as 16- or 24-bit PCM when that loses nothing.

Returns
true if the buffer is now compact. Verified sample by sample: any value that is not exactly k / 2^15 (or k / 2^23) with an integer k in range, including NaN and anything over full scale, leaves the buffer float32 and unchanged. Main/import thread only.
