Detailed Description

Windows (V82-H8): the plugin's editor in a top-level window the helper owns.

Window messages are pumped by the command loop's reader (HelperLineReader.h) on this same thread, the one that loaded the plugin; the window procedure only notes a close or a new size, and service() acts on it between commands, as on X11.
