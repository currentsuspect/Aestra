Detailed Description

OpenGL 3.3+ renderer implementation for Aestra UI.

Features:

  • Shader-based rendering
  • Batched draw calls
  • SDF text rendering
  • Post-processing effects

void AestraUI::NUIRendererGL::drawTexture ( const NUIRect &  bounds,
const unsigned char *  rgba,
int  width,
int  height 
)
overridevirtual

Draw a texture from raw RGBA pixel data.

This method creates a temporary OpenGL texture from the provided RGBA data, renders it to the specified bounds, and cleans up the texture immediately. It's designed for one-time rendering of rasterized content (e.g., SVG icons).

Parameters
boundsThe target rectangle where the texture should be rendered
rgbaPointer to RGBA pixel data (4 bytes per pixel: R, G, B, A)
widthWidth of the source image in pixels
heightHeight of the source image in pixels
Note
The texture is created and destroyed within this call. For frequently rendered textures, consider using createTexture() + drawTexture() instead.
The current transform and opacity state will be applied to the rendering.

◆ renderCachedOrUpdate()

bool AestraUI::NUIRendererGL::renderCachedOrUpdate ( uint64_t  widgetId,
const NUIRect &  destRect,
const std::function< void()> &  renderCallback 
)
overridevirtual

Render a cached widget, rebuilding it on demand when invalid.

The render callback should draw the widget contents at its normal absolute coordinates. When rendering to the cache, callers typically push a transform like (-destRect.x, -destRect.y) so absolute draws land at (0,0) in the FBO.

Returns
true if the cache was used (or updated), false if caching isn't available.
