void Aestra::MuseAgent::MuseSocketClient::setReadTimeoutMs ( int  milliseconds)

Give recv a deadline, so a connected-but-silent peer cannot hang the caller forever.

0 restores blocking-until-answered.

Call after connect(); it applies to the open socket. Requests that do real work (render_song bounces a whole timeline) need a generous value — this is a hang guard, not a latency budget.
