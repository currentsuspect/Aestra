Detailed Description

Undoable reorder of a plugin within a chain (Automation Identity Contract I7).

The instance identity travels with the plugin (movePlugin/swapPlugins carry it), so a reorder is a rearrangement, never a retarget: automation addressed by deviceInstanceId is untouched. Undo restores the exact original ordering and identities; redo reapplies. Nothing is minted, regenerated, or swapped as a side effect. Invalid moves throw, leaving both the chain and the command history untouched.
