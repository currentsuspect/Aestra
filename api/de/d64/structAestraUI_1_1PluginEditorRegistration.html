Detailed Description

One plugin id and the editor name it maps to.

No factory here on purpose. A factory is a std::function that constructs a concrete editor, so a table holding them could only be consumed by a translation unit that links all eleven editor .cpp files – which drags the NUI widget stack and thorvg into a test whose entire job is checking that eleven strings are spelled correctly and resolve.

So the id/name table is header-inline and the factories live in the .cpp, keyed by editorName. The .cpp stringises each factory's name from the editor type itself and static_asserts that its list and this table name the same set of editors, so neither list's order matters and a mismatch does not build.
