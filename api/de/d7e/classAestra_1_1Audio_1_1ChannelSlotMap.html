Detailed Description

Maps channel IDs to dense slot indices for lock-free buffer access.

Channel IDs are not necessarily dense (e.g., after track deletion, IDs may be 1, 3, 5). The MeterSnapshotBuffer and ContinuousParamBuffer use dense slot indices (0, 1, 2...) for cache efficiency. This class translates between them.

Thread Safety:

  • rebuild() must be called only at safe points (stop transport, track add/remove)
  • After rebuild(), getSlotIndex() and getChannelId() are safe to call from any thread (read-only access to immutable data after rebuild)

RT Safety:

  • No heap allocation in any method. All storage is fixed-size std::array.
  • getSlotIndex() is O(n) with n <= 127 (linear scan), deterministic and cache-friendly.
  • getChannelId() is O(1) direct index lookup.

Requirements: 12.5 - Each channel control parameter SHALL be identified by stable (channelId, paramId) pairs for automation readiness.
