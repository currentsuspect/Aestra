Detailed Description

Step lanes under an open Arsenal row (V81-AR1, FD-27 point 4): the values behind the pads, drawn as bars you drag, lined up with the pads above.

Lanes are fitted to the unit (FD-27 "type-fitted lanes"): every unit gets Velocity; a pitched sampler also gets Pitch (semitones from the root) and Length (the gate), because those are the fields its playback reads. The value rules and the geometry are pure; one drag is one undo step.
