Detailed Description

ITU-R BS.1770-4 K-weighting, the one place its coefficients are computed.

Two biquads in series: a high-shelf pre-filter (the head's acoustic effect) then the RLB high-pass. The live meter (AudioEngine) and offline analysis (AudioAnalysis) both use these, so a render's measured loudness and the master meter's agree by construction.

Coefficients use the normalised form y = b0 x + b1 x1 + b2 x2 - a1 y1 - a2 y2.
