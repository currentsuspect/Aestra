17// ---------------------------------------------------------------------------
18// Shared modal-dialog chrome
19//
20// AestraPanelWindow below is the DAW's panel chrome, but it is a base class: a
21// surface that owns dragging, content clipping and a close button, which the
22// plugin editors inherit. The modal dialogs (Save Changes, Recovery, Export,
23// Settings) cannot inherit it without giving up their own layout and modality,
24// and every one of them had therefore grown its own idea of what an Aestra
25// panel looks like — Settings open-coded a passable copy, Recovery drew a
26// centred 20px bold heading inside a plain card with no title bar at all.
27//
28// These two functions are the same chrome as a free painter, so a dialog gets
29// the title-bar language by calling one function instead of by inheriting a
30// component it is not. Constants live once, here, alongside the class that uses
31// them (spec 2 §5).
32// ---------------------------------------------------------------------------
