Detailed Description

Bounce in Place (V8-W5): replace clips with the audio their track made of them.

The caller has already rendered the channel's own output over the clips' span (AudioExporter with captureMixerChannelId: inserts, insert-parameter automation, delay compensation; fader and pan stay live afterwards). This command is the project edit, as ONE undo step:

  1. the rendered audio becomes a new source and pattern;
  2. the selected clips are removed and one clip spanning them takes their place;
  3. the channel's inserts are bypassed, so the effects are not applied twice;
  4. the channel's plugin-parameter automation is muted, for the same reason.

Nothing is deleted: removed clips, the previous bypass flags and the muted curves' points are all kept so undo restores them exactly, and redo reuses the rendered file instead of rendering again.
