Detailed Description

Adapter for the Anthropic Messages API (BYOK performance tier).

POST {baseUrl}/v1/messages with x-api-key auth. Requests stay minimal — model, max_tokens, system, messages, tools — no sampling parameters (removed on current models) and no thinking configuration.
