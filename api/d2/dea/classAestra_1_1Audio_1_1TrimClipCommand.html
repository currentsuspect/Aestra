Detailed Description

Command to trim a clip's start/end positions.

Contract (#744): a left-edge trim moves the timeline start AND advances the source read offset by the same musical amount so the right edge stays pinned; a right-edge trim changes only the visible end/duration. Both directions must go through the command history so undo, dirty state, autosave, recovery and serialization agree. For audio clips, durationSeconds is kept canonical (the serializer prefers it over beats) and the source-offset advance lands in sourceOffsetSeconds, from which the legacy beat-domain field is re-derived on load.
