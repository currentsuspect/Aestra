Detailed Description

Double-precision linear-ramp parameter smoother for zipper-free automation.

Advances one sample at a time via next(). Call beginRamp() after setTarget() to start a finite-length linear ramp; snap() jumps immediately. NaN/Inf values are sanitized at every entry point to prevent propagation.
