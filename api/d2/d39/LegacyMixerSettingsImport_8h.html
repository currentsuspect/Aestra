Detailed Description

One-time, one-way import of the mixer inspector preference from the file the app used before V8-C14 (~/.config/aestra/mixer_settings.json).

FD-23 step 3 moved that preference into the shared UISurfaceStore. Its open question (d) allowed "migrate or leave compatible", but ruled that compatibility "must not mean two long-lived paths to the same preference". So this reads the old file only while the store has no value for the preference, copies it in once, and from then on the store alone is consulted. Nothing writes the old file any more; it is left in place as a harmless orphan rather than deleted.

Import-only code. When it can be deleted (e.g. after a public release that shipped the migration) is an open founder decision recorded in the vault.
