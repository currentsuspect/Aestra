308 // -------------------------------------------------------------------------
309 // Synchronization policy (#391)
310 //
311 // m_mutex guards ALL non-atomic manager state below (drivers, active driver,
312 // current config/callback, preferences, fallback reason, driver-mode callback,
313 // auto-scale bookkeeping, health-monitor bookkeeping). Public methods acquire
314 // it and delegate to *Locked() helpers that assume it is held; the helpers
315 // compose without re-locking. Rules that keep this deadlock-free:
316 // - The health-monitor thread is only ever started/stopped (joined) at the
317 // public boundary, never while m_mutex is held. checkDriverHealthLocked
318 // runs under the lock but never joins itself.
319 // - m_driverModeChangeCallback is captured under the lock and invoked only
320 // after the lock is released (it may re-enter a manager getter).
321 // - The realtime audio callback never touches this manager, so m_mutex is
322 // never acquired from the audio thread.
323 // - m_activeDriver is a borrowed pointer into m_drivers; m_drivers is only
324 // cleared under the lock (shutdown), so the pointer is valid for the whole
325 // of any locked section and is never used outside one.
326 // -------------------------------------------------------------------------
327 mutable std::mutex m_mutex;
