329 // -------------------------------------------------------------------------
330 // Synchronization policy (#391)
331 //
332 // m_mutex guards ALL non-atomic manager state below (drivers, active driver,
333 // current config/callback, preferences, fallback reason, driver-mode callback,
334 // auto-scale bookkeeping, health-monitor bookkeeping). Public methods acquire
335 // it and delegate to *Locked() helpers that assume it is held; the helpers
336 // compose without re-locking. Rules that keep this deadlock-free:
337 // - The health-monitor thread is only ever started/stopped (joined) at the
338 // public boundary, never while m_mutex is held. checkDriverHealthLocked
339 // runs under the lock but never joins itself.
340 // - m_driverModeChangeCallback is captured under the lock and invoked only
341 // after the lock is released (it may re-enter a manager getter).
342 // - The realtime audio callback never touches this manager, so m_mutex is
343 // never acquired from the audio thread.
344 // - m_activeDriver is a borrowed pointer into m_drivers; m_drivers is only
345 // cleared under the lock (shutdown), so the pointer is valid for the whole
346 // of any locked section and is never used outside one.
347 // -------------------------------------------------------------------------
348 mutable std::mutex m_mutex;
