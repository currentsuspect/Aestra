◆ targetMixerRoute

int Aestra::Audio::UnitInfo::targetMixerRoute {-1}

Timeline lane assignment compatibility field.

Current behavior maps this integer directly to route mode:

  • < 0 routes unit output to master preview path.
  • >= 0 routes unit output to the Timeline track at that index.

Arsenal currently participates in the main engine render path. Timeline remains arrangement/export authority, and export follows live processBlock routing behavior.
