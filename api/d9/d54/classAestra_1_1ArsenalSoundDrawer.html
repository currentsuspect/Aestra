Detailed Description

The sound drawer under an open sampler row's sound strip (V81-AR1, FD-27 point 4): the sounds beside the current one as a searchable list.

Arrow keys and clicks swap the row's sound while the pattern loops (the swap is gap-free, V81-E3), Enter keeps the one you are on, Esc puts back the one you started with.

The rules are pure: filtering, selection, the visible window, and what a key does. Drawing and hit-testing take the same state, so the tests drive the real thing.
