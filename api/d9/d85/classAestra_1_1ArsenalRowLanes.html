Detailed Description

Which Arsenal rows are open, and the glue between them and the lanes (V81-AR1, FD-27 point 4): the small caret on each row, the extra height an open row adds to the rack, and the pointer routing for the lanes.

The panel owns one of these and calls it from layout, render and pointer handling, so the lane rules and the widget wiring stay out of the (size-pinned) panel file.
