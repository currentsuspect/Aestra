Detailed Description

Single-writer seqlock carrying a ScheduleSnapshot from the audio thread.

The scheduler needs the frame, the loop it is measured in and the queue epoch as ONE tuple: a frame paired with another block's loop schedules a whole pass off, and a frame paired with a newer epoch revives events planned from a stale position. The writer never waits (publish is a handful of relaxed stores bracketed by a sequence counter); readers retry a bounded number of times.
