Detailed Description

VST3 plugin instance implementation.

Wraps a VST3 plugin module and provides the IPluginInstance interface. Handles:

  • Module loading (.vst3 bundles)
  • COM/IPluginFactory management
  • IComponent and IAudioProcessor lifecycle
  • IEditController for parameters and GUI
  • ProcessData setup for audio callbacks

◆ openEditorEmbedded()

bool Aestra::Audio::VST3PluginInstance::openEditorEmbedded ( const std::function< std::uintptr_t(int width, int height, bool resizable)> &  makeWindow,
EditorLoopPump &  pump,
std::function< void(int width, int height)>  requestResize 
)

Open the editor in a top-level window the caller creates: an X11 window on Linux (V82-H3), an HWND on Windows (V82-H8).

On Windows the plugin runs its own Win32 timers, which the caller's message pump serves.

The plugin's view is created first so its preferred size is known; makeWindow is then called with that size and whether the plugin can be resized, and returns the X11 window id (0 = could not) the view is attached to ("X11EmbedWindowID"). The plugin drives itself through Linux::IRunLoop, which feeds pump: the caller's GUI thread polls the descriptors and timers the pump holds. When the plugin asks for another size (IPlugFrame::resizeView) requestResize runs, then the view is told the size took. Returns false, with nothing left open, if the plugin has no X11 editor. Call on the thread that owns the window and runs the pump.
