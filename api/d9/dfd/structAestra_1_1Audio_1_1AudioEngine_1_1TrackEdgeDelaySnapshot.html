Detailed Description

PDC v2 (P4b.2): per-track per-edge compensation snapshot for tests and tooling.

NOT RT-SAFE: read from main / control thread only.

Returns the node latency/compensation values and per-edge delay state that the off-RT apply pass wrote into TrackRTState for the given track index. The buffer contents themselves are not exposed; only the values the RT-side P4b.3 consumer will read.
