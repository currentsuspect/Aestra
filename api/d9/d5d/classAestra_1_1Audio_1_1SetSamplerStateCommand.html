Detailed Description

One undo step for a gesture in the Sample Editor (a slider drag, a trim, an envelope handle, a mode key).

The gesture has already changed the sampler live, so the command is recorded with pushExecuted: it carries the state before and after, and undo or redo writes the other one back, saves the unit's plugin state, and tells the editor (if it is open on this unit) to show it.
