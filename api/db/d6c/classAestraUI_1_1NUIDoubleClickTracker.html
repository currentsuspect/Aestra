Detailed Description

Double-click detection for platforms that never populate the event flag.

Nothing in the tree assigns NUIMouseEvent::doubleClick, so any control that only checks that flag has a dead code path. Every control that wanted a double-click therefore paired up quick presses by hand, each with its own timestamp field and its own copy of the threshold — which is exactly how the window silently drifts apart between controls when one copy gets tuned.

Usage:

if (event.pressed && event.button == NUIMouseButton::Left) {
if (m_clickTracker.registerPress() || event.doubleClick) {
resetToDefault();
return true;
}
}

The platform flag is still worth OR-ing in: if a backend ever starts setting it, that path keeps working.
