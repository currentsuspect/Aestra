Detailed Description

Where every version sits on the History timeline (SPEC-017, V81-V1): one lane per branch in the order the branches first appear, time running left to right, a link from each version to its parent.

Pure: it takes the manifest's versions and a rectangle and returns positions, so the layout is testable without a window.
