Detailed Description

What a rendered file sounds like, as numbers a script can check.

Pure: computed from interleaved float samples, so it is the same whether the samples came from an export, a test, or a file on disk. The point is that an agent (or CI) can judge a render without listening to it – the half of the verification loop that otherwise needs a human.
