4// FLAC and MP3 export (v0.8.2, FD-61). The encoders are loaded when an export asks for them, not linked: libFLAC
5// (BSD) and libmp3lame (LGPL, kept dynamically linked as FD-61 decided). A format whose library is not on the
6// machine is reported unavailable rather than failing at link time, so Aestra builds and runs without either.
7//
8// The exporter renders exactly as for WAV and hands each finished block to write() through its block sink, so the
9// encoded file is the same render as a WAV export, quantised by the encoder instead of the WAV writer.
