Detailed Description

Math utilities for mixer UI dB/linear conversions and formatting.

Audio thread writes LINEAR peaks (0..1), UI converts to dB for display. UI smoothing happens in dB space (looks nicer, more natural decay).

Requirements: 8.1, 8.2 - Fader range from -infinity dB to +6 dB, minimum value maps to ≤ -90 dB and displays "-∞".
