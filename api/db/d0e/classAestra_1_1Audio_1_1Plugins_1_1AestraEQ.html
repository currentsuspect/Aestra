◆ onParameterChanged()

void Aestra::Audio::Plugins::AestraEQ::onParameterChanged ( uint32_t  ,
float   
)
inlineoverridevirtual

Called after a parameter is stored, so a plugin can invalidate derived state (filter coefficients, oversampling config) or mirror the value into a smoothed copy.

Not called for a rejected value.

Runs on the AUDIO THREAD: AudioEngine::renderTrack applies plugin- parameter automation through setParameter() every block. An override must stay non-blocking – set a flag, store a value – and must carry AESTRA_RT_NONBLOCKING itself so the RT effect check can see its body.
