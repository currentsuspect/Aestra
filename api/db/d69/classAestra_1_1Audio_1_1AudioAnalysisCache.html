Detailed Description

Each analysis computed once: results kept by content key.

The key names the audio, not where it lives: a render's RenderSummary hash (plus rate and channel count), or a file's path with its size and mtime, so an edited file is measured again. Thread-safe; the analysis itself runs outside the lock, and two callers racing on one key both get a valid result.
