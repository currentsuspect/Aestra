Detailed Description

Interleaved audio FIFO owned by one real-time thread.

The sandbox exchanges audio with its helper in fixed-size chunks while the engine calls it with whatever block it is rendering (a loop wrap splits a callback in two; an oversized driver block is split into capacity chunks). These FIFOs sit between the two so the transport delay stays one constant chunk however the callback is cut. reset() allocates (non-RT); every other call is allocation-free and bounded.
