Detailed Description

Groups multiple commands into a single undoable transaction.

Usage: auto macro = std::make_shared<MacroCommand>(); macro->setName("Move Clips"); macro->addCommand(cmd1); macro->addCommand(cmd2); commandHistory.pushAndExecute(macro);
