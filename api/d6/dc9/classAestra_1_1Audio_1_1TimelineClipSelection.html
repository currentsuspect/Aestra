Detailed Description

Multi-clip selection authority for the timeline (#848, marquee select).

Intent-based like TimelineTrackSelection: Replace clears the set first, Toggle flips membership, Add keeps existing entries. The anchor clip (last non-toggle selection) stays available for single-clip operations.
