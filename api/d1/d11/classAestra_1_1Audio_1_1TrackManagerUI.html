Detailed Description

UI wrapper for TrackManager.

Provides visual track management interface with:

  • Track layout and scrolling
  • Add/remove track functionality
  • Visual timeline integration
  • Drag-and-drop support for files and clips

◆ beginGridMarquee()

bool Aestra::Audio::TrackManagerUI::beginGridMarquee ( const ::AestraUI::NUIMouseEvent &  event)

A left press on empty grid in the Select tool (SPEC 3 §1.2): the default marquee.

A plain press is the selection exit: it clears the clip selection and the ruler zone. With Shift/Ctrl the press keeps them, so the band adds or toggles. Either way a marquee starts; a release that never travelled is a click and selects nothing (marqueeReleasePlan).

Returns
True if the press started a marquee (the Select tool, left button, none active).
