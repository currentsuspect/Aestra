Detailed Description

The ok envelope and the executionMs stamp, paired.

Each family builds one on entry, so executionMs measures that family's work. Before the split a single clock started just before the dispatch chain, which for a verb handled late in the chain also counted the verbs already tried and rejected. Both readings are "how long serving this request took"; this one stops crediting a routing graph for the session queries that missed.
