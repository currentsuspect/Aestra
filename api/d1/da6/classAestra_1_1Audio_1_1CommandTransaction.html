Detailed Description

Groups multiple commands into a single undoable transaction (v1.0)

Use CommandTransaction to group related edits into a single undo step. This is essential for operations that touch multiple parts of the project.

Example: auto transaction = std::make_shared<CommandTransaction>("Move Clips"); transaction->add(clipMoveCommand1); transaction->add(clipMoveCommand2); transaction->add(clipMoveCommand3); history.pushAndExecute(transaction); // Undoes all 3 as one step

void Aestra::Audio::CommandTransaction::markExecuted ( )
inline

Adopt members that were already executed one-by-one.

For stepwise batch execution (each member validated against the state its predecessors produced): the caller executes members itself, then marks the transaction executed so undo/redo treat it as one applied step. Pair with CommandHistory::pushExecuted().
