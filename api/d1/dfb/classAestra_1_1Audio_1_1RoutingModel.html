Detailed Description

Read-only view of the routing graph (V8-C15, FD-29).

A snapshot taken from TrackManager at a point in time. It answers the questions a routing UI asks — what feeds this channel, where does it go, which channels share an output — without touching the live graph. It never decides whether a route is legal: that stays in TrackManager::canRouteTo, and every mutation still goes through the routing commands.

Master is spelled kMaster (0, model space) everywhere in this view; the engine's 0xFFFFFFFF spelling is normalised on the way in.
