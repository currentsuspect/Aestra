Detailed Description

Thread-safe arena allocator for real-time audio buffer management.

A bump allocator that pre-allocates a large block and hands out pointers via atomic pointer bump. No per-allocation locks, no fragmentation, O(1) allocation. Reset clears everything at once.

Usage: AudioArena arena(1024 * 1024); // 1 MB float* buf = static_cast<float*>(arena.allocate(1024 * sizeof(float), alignof(float))); arena.reset(); // free all at once

Thread safety:

  • allocate() is lock-free (atomic CAS loop)
  • reset() is NOT thread-safe — caller must ensure no concurrent allocate()
  • Designed for single-producer (audio thread allocate), single-consumer (reset on idle)
