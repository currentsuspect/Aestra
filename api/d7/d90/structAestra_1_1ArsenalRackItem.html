Detailed Description

Where the Arsenal's rows and group headers sit (V81-AR1, FD-27 point 2): "a grouped rack".

Units sit under their UnitGroup (Drums, Synth, Audio, then anything else), each group under a header with its count, in the order the units were made inside a group. The rule and the positions are pure so the panel's layout, scrolling and drag-and-drop all read one answer instead of each assuming uniform rows.
