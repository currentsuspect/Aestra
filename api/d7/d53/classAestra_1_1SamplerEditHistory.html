Detailed Description

Makes the Sample Editor's controls undoable (a v0.8.2 candidate the founder asked for on 2026-10-13).

The editor changes the sampler live while a control is dragged and says when the gesture is over. This keeps the state the sampler had when the editor last synced to it (begin); at the end of a gesture (commit) it saves the unit's plugin state as before and, when something changed, records one undo step from that baseline to now.
