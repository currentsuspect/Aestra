Detailed Description

V8-C14 step 5b: the pure half of plugin-editor position persistence.

FD-23's rule for editors: an editor stores its anchor only — its size is the plugin's intrinsic size, never a user preference — under editor.<id>, as a local user preference, never project state. These helpers assemble that preference from measured inputs; the controller resolves it through Layout::resolveAnchoredPlacement and persists it through the app-provided anchor callbacks (the store itself lives app-side; AestraUI must not include Source/). Header-only; links nothing.
