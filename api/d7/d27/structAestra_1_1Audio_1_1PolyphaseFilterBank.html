Detailed Description

Precomputed polyphase filter bank.

Stores windowed sinc coefficients organized by fractional phase. Generated once during configure(), used in process() with zero overhead.

Layout: coeffs[phase][tap] where:

  • phase ∈ [0, POLYPHASE_PHASES)
  • tap ∈ [0, numTaps)
