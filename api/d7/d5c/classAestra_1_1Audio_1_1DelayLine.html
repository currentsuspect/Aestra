Detailed Description

template<typename T, size_t Capacity>
class Aestra::Audio::DelayLine< T, Capacity >

Fixed-capacity delay line for RT-safe plugin delay compensation.

Uses a ring buffer with compile-time capacity. No allocations after construction. Thread-safe for single writer, single reader (RT audio thread).

Maximum delay: 16384 samples (~340ms @ 48kHz, ~170ms @ 96kHz)
