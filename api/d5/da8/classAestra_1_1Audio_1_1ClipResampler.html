Detailed Description

High-quality clip resampler using polyphase Sinc64.

Provides sample-accurate resampling for clip playback with pitch shifting. Uses the optimized Sinc64Turbo polyphase filter bank (see the quality note on ClipResamplingQuality above for measured performance).

Usage:

ClipResampler resampler;
resampler.setQuality(ClipResamplingQuality::High);
float sample = resampler.getSample(audioData, numFrames, 2, sourcePosition);
