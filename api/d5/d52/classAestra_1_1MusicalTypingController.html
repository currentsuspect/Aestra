Detailed Description

Converts computer-keyboard events into live MIDI notes.

This class owns the key latch and note lifetime independently from UI focus routing. Callers decide when keyboard input is eligible, while this class guarantees one note-on per physical press and a matching note-off for the original unit/note when the key is released.
