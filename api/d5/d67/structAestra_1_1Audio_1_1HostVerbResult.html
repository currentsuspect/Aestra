Detailed Description

What a host verb returns.

Deliberately not "arbitrary JSON". A handler must say whether it succeeded, and a failure must carry a machine-readable code — agents that have to pattern-match prose to find out what happened will do it badly, and the code is what lets a caller distinguish "no such device" from "device busy" without parsing English.
