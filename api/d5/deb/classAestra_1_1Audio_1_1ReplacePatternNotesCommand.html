Detailed Description

Replace a MIDI pattern's notes, and optionally its length, as one undo step (V82-M3)

The Muse piano-roll verbs (add_notes, delete_notes, duplicate_notes) compute the new note list up front and hand it here. Unlike EditPatternNotesCommand, which the editor pushes already applied, this one applies on execute(), the way CommandHistory runs a verb. The previous notes and length are captured at execute, so undo restores exactly what was there. A duplicate that runs past the pattern's end grows the pattern in the same step.
