Detailed Description

Carries one recorded take from the audio thread's capture ring to disk while it is still being recorded ("never lose a session").

The audio thread writes frame f of a take into ring[f % capacity] and then publishes the running frame count. drain() runs off the audio thread: it copies every frame published since the last drain into memory and appends it to a .partial WAV beside where the finished take will go. The WAV header is rewritten on every drain and the file is synced about once a second, so after a crash the partial file is a playable take up to the last drain.

The ring only has to cover the time between drains, so the length of a take is limited by memory and disk, not by the ring.

If a drain comes too late and the audio thread has already overwritten frames, those frames are written as silence and counted in lostFrames(), so everything after them stays at its true position on the timeline.

Not thread-safe: one thread drains at a time (TrackManager holds its recording mutex around every call).
