255 // === Synchronised dual playback (V81-E2, FD-26) ===
256 //
257 // A reference (side B) runs in lockstep with the mix (side A) once one is set: both are read every block at
258 // the same position (plus an optional offset), so a switch is a short gain ramp between two live signals, never
259 // a seek, and anything applied after the sum (the DSP chain) hears both alike. With no reference set, playback
260 // is exactly what it was.
261
