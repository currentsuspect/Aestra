Detailed Description

Multi-tier audio engine diagnostics.

Captures scheduling jitter, dispatch latency, callback duration, xruns, RT violations, plugin health, and denormal events.

All fields are populated by the audio thread and read by the UI/telemetry thread via a seqlock snapshot mechanism.
