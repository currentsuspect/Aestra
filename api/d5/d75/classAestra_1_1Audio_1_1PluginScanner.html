Detailed Description

Plugin scanner for discovering installed plugins.

Scans filesystem paths for VST3 and CLAP plugins, extracting metadata and building a searchable plugin database. Supports async scanning with progress callbacks and caching for fast startup.

Usage:

PluginScanner scanner;
scanner.addSearchPath("C:/Program Files/Common Files/VST3");
scanner.addSearchPath("C:/Program Files/Common Files/CLAP");
scanner.scanAsync([](const std::string& path, int current, int total) {
std::cout << "Scanning: " << path << " (" << current << "/" << total << ")\n";
});

◆ cancelAndJoin()

void Aestra::Audio::PluginScanner::cancelAndJoin ( )

Cancel scan and join the scanner thread.

Call this during explicit shutdown to ensure the scan thread is stopped before static singletons are destroyed. This prevents the hang caused by PluginScanner::~PluginScanner() joining a thread that hasn't checked the cancel flag yet.

Safe to call multiple times. No-op if no scan is running.
