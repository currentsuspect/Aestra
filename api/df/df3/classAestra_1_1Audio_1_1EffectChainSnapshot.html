Detailed Description

Immutable snapshot of an entire effect chain.

This snapshot is designed to replace raw EffectChain* access in the audio thread. It is built from the mutable EffectChain and published atomically.

Pass 1 implementation: snapshot type and builder only. Future passes will add publication and AudioGraph consumption.
