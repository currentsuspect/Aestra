Detailed Description

RT-safe continuous parameter buffer for mixer controls.

Stores per-channel fader/pan/trim values in a dense slot-indexed array. UI thread writes values via atomics, audio thread reads them without locking.

Dirty bits allow the audio thread to avoid re-reading unchanged parameters.
