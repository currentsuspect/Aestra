Detailed Description

Micro profiler for frame timing analysis.

Measures and tracks:

  • Render time (CPU work)
  • Swap time (GPU sync/VSync)
  • Sleep time (frame pacing)
  • Total frame time
  • FPS (actual vs target)

Usage: profiler.beginFrame(); // ... render work ... profiler.markRenderEnd(); swapBuffers(); profiler.markSwapEnd(); // ... sleep ... profiler.endFrame();
