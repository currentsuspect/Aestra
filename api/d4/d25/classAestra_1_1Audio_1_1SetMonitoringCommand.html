Detailed Description

Command to toggle a channel's input-monitoring arm state.

Mirrors SetMuteCommand: the mixer slot is the input-monitoring trigger (FD-14 #6), and routing the toggle through the command history gives the project dirty flag and undo/redo parity with mute/solo/pan. The engine monitor-route snapshot refreshes through setArmed's own notification.
