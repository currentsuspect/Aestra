Detailed Description

Per-channel UI state for the mixer.

Stores channel identity, control state, and meter smoothing state. Meter values are stored in dB space for natural-looking decay.

Requirements: 3.1 - Each channel strip SHALL display track name and color. Requirements: 12.3 - Meter smoothing state per channel.
