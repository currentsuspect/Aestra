Detailed Description

Command to add an Arsenal unit (undoable)

Creating a non-audio unit also creates its default MIDI pattern (via UnitManager). Undo removes the unit; the default pattern is left behind, matching how the Arsenal panel removes units. Like AddChannelCommand, redo after undo mints a fresh unit ID.
