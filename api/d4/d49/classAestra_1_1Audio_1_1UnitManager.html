◆ publishSnapshot()

void Aestra::Audio::UnitManager::publishSnapshot ( )

Publish the current Arsenal state as an immutable snapshot.

Call from the main/control thread whenever Arsenal state changes (unit created/destroyed, route changed, plugin attached, mute/solo/enabled changed). The audio thread reads the published snapshot via getAudioSnapshot() without allocating, locking, or mutating project state.
