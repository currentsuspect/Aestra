Detailed Description

Stereo level meter widget for the mixer UI.

Displays two vertical bars (L/R) with green/yellow/red zones, peak hold indicators, and clip latch indicators.

Accepts dB values (already smoothed by MixerViewModel). Uses quasi-logarithmic scale for better visual feedback.

Requirements: 9.1, 9.2, 9.3, 9.4, 9.5, 15.3
