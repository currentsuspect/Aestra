Detailed Description

Project file validation and schema checking (v1.0)

Validates project files before loading to prevent crashes from corrupted or malformed data. Performs both structural and semantic validation.

Usage: ProjectValidator validator; auto result = validator.validateFile("project.aes"); if (!result.isValid()) { Log::error("Project invalid: " + result.getErrorSummary()); }
