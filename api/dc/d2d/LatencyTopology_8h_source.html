2// LatencyTopology — PDC v2 data model and pure solver.
3//
4// Architectural contract (see Aestra-Internals: aestra-docs/PDC-v2-Design.md §4.0):
5// * `LatencyGraph` is an immutable input artifact, built off-RT from routing state.
6// * `solveLatency(LatencyGraph) -> SolvedLatencyTopology` is a pure function.
7// No engine references, no globals, no I/O, fully deterministic.
8// * `SolvedLatencyTopology` is an immutable output artifact consumed by the
9// RT engine read-only. The RT engine never mutates it.
10// * Compensation values are derived render state. They are NEVER stored on
11// `AudioRoute` or any user-visible / serialized structure.
12//
13// P2 scope (this commit): types are introduced; solver reproduces v1 behavior
14// exactly (flat per-node, no graph traversal). Graph-aware DFS lands in P4.
