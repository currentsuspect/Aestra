Detailed Description

MIDI events waiting to ride the next sandbox chunk, with offsets in FIFO time.

Events arrive per callback with offsets into that callback; they leave per chunk with offsets into that chunk. Fixed capacity; an event that does not fit is dropped and counted by the caller.
