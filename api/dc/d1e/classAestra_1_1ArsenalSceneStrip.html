Detailed Description

The Arsenal's pattern scenes (V81-AR1, FD-27 point 1): every MIDI pattern is a chip, one click plays it, and "+" makes the next one.

Placement is pure (place): chips keep their widths, the active one is kept in view when they overflow, and the wheel scrolls the rest. The panel only owns an instance, feeds it the pattern list and forwards the pointer, so the panel file stays out of this rule.

◆ quietDefaults()

template<class TrackManagerT >
static std::vector< uint64_t > Aestra::ArsenalSceneStrip::quietDefaults ( const TrackManagerT &  tm)
inlinestatic

Every unit is born with its own pattern ("Kick Pattern").

Until it holds notes or sits in the timeline it is plumbing, not an idea, so the strip leaves it out (FD-27: patterns are the person's scenes). A kit of eight sounds would otherwise bring eight empty cards. Templated on the track manager to keep this header light.
