Detailed Description

Copies one mixer channel's output before it is routed to the master or a group (V8-W5 Bounce in Place, V8-S1 stems).

The buffer is post-insert and post-delay-compensation, and either before or after fader/pan (see arm()). The offline renderer arms it for the duration of one render and reads each block back after processBlock() on the same thread, so the audio thread only writes into storage that was reserved up front.
