Detailed Description

Central debug flag definitions for Aestra.

Use these flags to guard debug-only code that should NOT compile in Release builds. This prevents debug test signals from accidentally shipping to production.

Usage:

#if AESTRA_DEBUG_METERS
// This only compiles in Debug builds
correlation = fakeSweepValue;
#endif
