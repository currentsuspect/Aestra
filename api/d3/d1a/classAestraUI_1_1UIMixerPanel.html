Detailed Description

Main mixer panel container with channel meters.

This is a barebones implementation for Checkpoint 1 ("Meters Move"). Creates one UIMixerMeter per channel and lays them out horizontally. Future checkpoints will add faders, knobs, and full channel strips.

Requirements: 3.1 - Channel strips with fixed width (96-112px)
