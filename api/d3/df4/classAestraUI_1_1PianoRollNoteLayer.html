◆ connectSelectedNotes()

void AestraUI::PianoRollNoteLayer::connectSelectedNotes ( )

Elongate selected notes to connect to the following note (legato).

Each selected note's end is extended forward to meet the start of the next note in time; when nothing follows, it extends to the next snap/beat boundary instead. Only ever lengthens — never shortens.

void AestraUI::PianoRollNoteLayer::strumSelectedNotes ( double  spreadBeats)

Stagger the selected notes into an upward strum.

Notes are anchored at the earliest selected start and cascaded low-to-high pitch by spreadBeats each. No-op for fewer than two selected notes.
