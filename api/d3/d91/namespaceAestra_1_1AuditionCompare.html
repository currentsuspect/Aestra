Detailed Description

Everything Audition measures when a mix is set beside a reference (FD-26, V81-A): the loudness, stereo and tonal numbers of each, the sections of each, the waveform of each on one scale, and how much the reference is turned down (or up) so the two are heard at the same level.

Pure: decoded audio in, numbers out, so it is tested with generated signals and runs the same on a bounce, a render or a file.
