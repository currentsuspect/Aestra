Detailed Description

Automation clips (V8-A7): the operations, as pure functions on one curve.

A region (see AutomationRegion) is a span of a curve that moves, copies, splits and deletes as one object. The functions here only edit the curve; undo is the caller's snapshot of the lane's curves (EditAutomationCurvesCommand), and the engine is not involved because the points are what it plays.

Rules, each pinned by AutomationRegionsTest:

  • A curve with points and no regions has ONE implicit region over all its points; the first operation turns it into a stored one (materialize()).
  • Moving or copying onto another region is refused. Loose points under the destination are replaced (the clip overwrites what it lands on).
  • A region never moves before beat 0; the move is refused rather than clamped, so the clip's shape is never squashed.
  • Splitting cuts the SEGMENT between two adjacent points. It inserts nothing and changes no value, so the curve sounds the same whatever its tension.
